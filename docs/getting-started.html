getting started

Local setup and first checks

Requirements

  • Python 3.11.
  • uv.
  • Docker Desktop or Docker Engine with Compose.

Run fast tests

uv run pytest -q

These tests do not require Docker, NAS mounts, SCC credentials or real data.

Run the Docker smoke test

.\scripts\smoke_docker.ps1

The smoke test starts Redis and the worker/API stack, queues tasks.misc.test_sum, checks the result and removes the test stack.

Start the development stack

docker compose up --build

Open the API docs at:

http://localhost:8000/docs

Start the test stack

docker compose -f docker-compose.test.yml up --build

Default ports:

ServicePort
API18000
Redis6380
Flower5555

Build this documentation locally

No build step is required. Open docs/index.html directly in a browser.
